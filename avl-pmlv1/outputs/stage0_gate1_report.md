## 二、三大结构性病灶与 `AVL-PMLv1.1` 架构重构蓝图

Stage 0 证伪以 `0 元` 算力精准暴露了三处必须当场动刀的架构裂缝：

1. **病灶一（`Tri-State` 探针窃流 + `L_util` 噪声破坏路由 → `K_max=0` 零掉点 & `Kendall τ = 0.06`）：**
   * **根因：** 共享专家过胖（`256` 维 > 单路由专家 `192` 维）叠加全开 8 路探针基底 `probe_mix` 与 `g_norm = gates/(sum+0.25)` 衰减，吞噬了 `~90%` FFN 残差容量；延迟微步评分器 `u_post` 在未聚类随机专家上拟合噪声，反而干扰路由。
   * **重构 (`v1.1`)：** 严格执行 Gate 1 裁撤原则——**裁掉残差主路 `probe_mix` 与高开销 `L_util` 微步**；共享微专家瘦身为真微专家（`128` 维），路由全秩专家扩容至 `256` 维；改用**端到端可微 Aux-Free Top-K 路由 + 惊讶度/Engram 动态深度门控（简单槽 `k=1`，高难槽 `k=2`，归一化权重和恒为 `1.0` 零衰减）**，保留已被实证有效的**双极 Sinkhorn 联动图**与**轨二痛觉低秩签名**直接调制路由 logits（训练提速 `~3x`，强迫路由全秩专家扛起主力容量）。
2. **病灶二（单块硬塞两步依赖动态算子 → `L3-Hard` 崩到 `17.66%` vs `NL-CoT 98.75%`）：**
   * **根因：** 把 `s1` 与 `s2 = op1(s1, k2)` 两个强因果依赖步骤硬塞进同一个 16 槽双向块，动态算子树在 `Beat 0` 盲抄算子+`Beat 1/2` 级联时极易撞车。
   * **重构 (`v1.1`)：** 实行 **1 步 1 原子微块（`8` 槽微帧 × `2` 拍确定性分层去噪，总长仍为 `4×8 = 32` tokens = `4.5x` 压缩）**——`Beat 0` 并行揭开帧头与动态算子/操作数 `[OP, op_i, arg1, arg2]`，`Beat 1` 基于 100% 干净的前序块与本帧操作数计算 `[val_i, ⟨BIND⟩, ⟨REG_j⟩, flag]`，彻底消灭块内因果撞车；同时为块扩散补齐**跨块前缀 KV Cache 复用**，把纯 GPU 速度再拉高 `2x`。
3. **病灶三（`populate_ro_from_prompt` 被 `torch.no_grad()` 锁死 → `Level 2a/b` 规则外推 `11.88%`）：**
   * **重构 (`v1.1`)：** 训练态解除 `populate_ro_from_prompt` 的 `no_grad` 封印，使梯度经 `h_pml → S^RO → ro_init_proj` 端到端打通，激活轨一白板的零样本规则查表能力。

## 四、`v1.0 -> v1.1` 架构定型裁决与 Stage 0 最终收口建议

1. **已彻底证成（锁定进入 Stage 1/2/3）：**
   * **8 槽原子微块 + 前缀 KV `CUDAGraph`**：纯硅片推理速度 **`5.14x` (`B=32`) / `4.90x` (`B=1`)**，零泄露金丝雀通过，收敛种子（Seed 2026）在 20% 未见动态算子树上冲至 **`95.31%`**；
   * **去 `probe_mix` & 去 `L_util` + 瘦共享(`64`)/宽路由(`256`) + 零衰减自适应 Top-K**：彻底根治 `K_max=0` 零掉点假象（`L3-Hard` 掉点达 **`-42.03%`** / 均掉 **`-19.79%`**，`Level 1` 掉点达 **`-32.19%`**），收敛种子上 `Level 1` 以 **`67.19%` vs `41.56%`** 碾压静态 Top-2 且少开 `17%` 专家；
   * **Static Engram + 轨二痛觉烙印 + 16 槽湿水泥**：三项机制在 `v1.0` 与 `v1.1` 两轮验证中均保持极强正向净贡献（痛觉烙印 `+23%~+26%`、`0.0%` 复发；湿水泥 `+6%~+15%`；Engram `+11%~+30%`）。
2. **仅余两项定向收口（无需推翻架构，只需针对性微调即可 100% 封关 Gate 1）：**
   * **消除稀疏路由早期高方差（Seed Variance）**：给 `AVL-PMLv1.1` 加上 **10% 线性 LR Warmup + 温和 `lr_scale` + 1,500 步稀疏充分收敛**（或在 Stage 2/3 使用预训练 Dense→MoE Upcycling 权重而非从零随机初始化，天然消除随机初始化相变方差）；
   * **解锁 `Level 2a/b` 两跳查表（`S^RO`）**：将“解出查询索引 `q_i`”与“按 `q_i` 读 `S^RO[q_i]`”拆开到不同拍（`Beat 0` 解 `q_i` → `Beat 1` 查 `S^RO[q_i]` 得 `mapped` → `Beat 2` 算 `acc`），验证 `S^RO` 在零样本规则链上的真实增益。
