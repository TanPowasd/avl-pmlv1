一、湿水泥回渗、延迟落盘与 KV/白板读写可见性契约

# 1.1 三态白板隔离与读写规则

为消除"上一块末尾 16 槽可回渗重掩码"与"当前块需要读取上一块绑定寄存器"之间的并发冲突，轨一显式白板在推理期拆分为两层物理视图（显存增量 < 64 KB/请求）：


- **只读事实核 S^RO ∈ R^(64 × d\_m)**：预思考期由 Prompt 跨度编码一次性固化，全题只读。
- **已提交白板 S^RW\_commit ∈ R^(64 × d\_m)**：存放块 1 至块 b-2 以及块 b-1 非末尾槽位已冻结定稿的寄存器状态。
- **临时影子白板 S^RW\_draft ∈ R^(64 × d\_m)（带脏位掩码 dirty\_mask ∈ {0, 1}^64）**：存放块 b-1 末尾 1 个物理原子块（C\_chunk ≡ 16 槽）内尚未冻死的 ⟨BIND⟩ 写入结果。


核心可见性与原子提交协议：


1. **跨块读取不断链**：当前块 b 去噪期读取统一视图 S^RW\_view\[j\] = S^RW\_draft\[j\]（若 dirty\_mask\[j\] = 1）否则 S^RW\_commit\[j\]，确保块 b 引用块 b-1 刚绑定的 REG\_in 时读到最新结果。
1. **湿水泥重掩码同步**：当 d\_bwd > 0.55 触发上一块末尾 16 槽（记为 C\_{b-1,tail}）的 15%–30% 局部重掩码时，仅在 C\_{b-1,tail} 与当前块 b 组成的局部窗口（长度 16 + B）内同步重算 C\_{b-1,tail} 的 Paged KV 页，并重放这 16 槽内的 ⟨BIND⟩ 更新 S^RW\_draft；块 b-1 之前的所有历史 KV 页 100% 冻结不动，实现零级联失效（阶段 C 训练期以 25% 概率构造同构的 16 + B 合并双向块掩码并重放 S^RW\_draft，确保训推逐位等价）。
1. **延迟 1 帧原子落盘（Lazy Commit）**：待当前块 b 完成三拍去噪且未触发红灯熔断的瞬间，将块 b-1 的 S^RW\_draft 原子合并入 S^RW\_commit、清零 dirty\_mask，并将块 b 末尾 16 槽写入新 S^RW\_draft。若块 b 触发熔断回滚至 b\*-1，直接丢弃 S^RW\_draft 并从每 4 帧稀疏快照重演 ≤ 3 帧恢复 S^RW\_commit。

## 1.2 块内多帧打包与并发 ⟨BIND⟩ 顺序律

- **物理原子块锁定**：C\_chunk ≡ 16，单块（B ∈ {16, 32, 64}）允许无填充紧密串联多个短微步帧。
- **同块顺序扫描律**：若单个原子块内出现多个 ⟨BIND⟩ ⟨REG\_j⟩，严格按槽位索引 t 从左到右依次执行 Householder 覆写（Last-Write-Wins），禁止同槽并发写入。训练期并行前向与推理期帧尾落盘必须调用同一个顺序扫描核，并在本地关闭 TF32 下通过误差 < 1e-5 的逐位等价单测。
- **静态编译器约束**：数据编译阶段的确定性线性扫描寄存器分配器默认禁止在同一个 16 槽原子块内对同一寄存器 ⟨REG\_j⟩ 连续两次覆写，从源头减少块内写后读竞争。

## 2.2 轨一 PML 符号状态轨与黄红双灯公式（挂 8 核心层 l ∈ {4,8,12,16,20,24,28,32}）

### 1. 地址+内容混合读取与零初始化冷静门控

给定残差流 x\_t ∈ R^D（D=2560，d\_m=64；40M 规格 D=512，d\_m=32），拼接状态库 M\_t = \[S^RO; S^RW\_view\] ∈ R^(N\_slot × d\_m)（标准规格 N\_slot=128，40M 规格 N\_slot=64）、正交槽位地址嵌入表 E\_slot ∈ R^(N\_slot × d\_m) 及有效置信度掩码 m\_t ∈ \[0, 1\]^N\_slot：

**查询与地址混合键值：**q\_t = RMSNorm(x\_t W\_Q) ∈ R^(d\_m)，  K\_t = E\_slot + M\_t W\_K，  V\_t = M\_t W\_V

**读取分布与输出：**p\_attn = Softmax(q\_t K\_t^T / √d\_m + ln(m\_t + ε))，  r\_t = p\_attn V\_t ∈ R^(d\_m)，  h\_pml = r\_t W\_O ∈ R^D

**与左脑 Full GQA 并联融合：**h\_out = h\_gqa + tanh(α\_calm ⊙ (1 + γ\_FiLM(d\_b))) ⊙ h\_pml

其中 E\_slot 赋予对指定编号寄存器 ⟨IN\_k⟩ / ⟨REG\_j⟩ 的精确按名寻址能力（杜绝相近数值串槽与长链寻址失明）；α\_calm ∈ R^D 零初始化，保证 0 步手术不破坏原 Qwen3-4B 分布。

### 2. 后缀 ⟨REG\_j⟩ 槽触发带擦除门 Householder 覆写（零反传）

严格在紧随 ⟨BIND⟩（新绑/复用覆写）或 ⟨VERIFY⟩/⟨COMMIT⟩（同变量重申校验）之后的后缀寄存器槽 ⟨REG\_j⟩ 处触发写入：由该槽 Token ID 直接解析物理槽号 j ∈ {0..63}（兼容阶段 B 因果 AR 热身与阶段 C 块扩散），取该槽隐状态 h\_reg 生成归一化方向 k\_j = Normalize(W\_k h\_reg)、旧态保留门 γ\_keep = sigmoid(w\_γ^T h\_reg) ∈ (0, 1)、子空间擦除门 β\_j = sigmoid(w\_β^T h\_reg) ∈ (0, 1)、写入步长 η\_j = sigmoid(w\_η^T h\_reg) 与新值向量 v\_j = W\_v h\_reg：

**带擦除门一步覆写：**s\_raw = γ\_keep · (I - β\_j k\_j k\_j^T) s\_old + η\_j v\_j

**状态归一化与置信度更新：**S^RW\_draft\[j\] = RMSNorm(s\_raw)，  m^RW\[j\] = min(1, 0.5 · γ\_keep · m^RW\[j\] + 0.5 · η\_j + 0.35)

### 3. 黄红双灯纯前向解耦计算（BIND 复用免误报）

**黄灯（认知惊讶 u\_epistemic ∈ \[0, 1\]）：**u\_epistemic = 0.5 · H(p\_attn) / ln(N\_slot) + 0.5 · clip(‖W\_pred x\_t - r\_t‖\_2 / (‖r\_t‖\_2 + ε), 0, 1)，仅作用于下游路由门槛降阈，绝不触发回滚。

**红灯（逻辑冲击 u\_acute ∈ \[0, 1\]）：**u\_acute = max(p(⟨CONTRA⟩), c\_wb, I\_sandbox)

**白板校验冲突度（解耦死亡槽位复用）：**c\_wb = I\_reassert · relu(-cos(s\_old, v\_j)) · m^RW\[j\]

其中 I\_reassert ∈ {0, 1} 仅在前导算子为 ⟨VERIFY⟩ / ⟨COMMIT⟩（或对未回收活跃假设槽重申）时取 1；当线性扫描编译器回收死亡寄存器执行常规新变量 ⟨BIND⟩ 赋值时置 I\_reassert = 0（同时令 γ\_keep → 0 清净旧槽），彻底杜绝 30–45 步长链寄存器复用误触红灯假熔断。熔断触发条件：单帧 u\_acute ≥ 0.65 或连续两帧 u\_acute ≥ 0.45 立即触发在线双帧熔断（每题上限 2 次）。

## 2.3 三态自调优 MoE、双极关联图与两大防崩溃护栏

### 1. 全员低秩试讲、轨二双极经验显式方程与有向阻尼关联图

**密集低秩试讲与基础分：**z\_i = SiLU(x U\_i) ∈ R^r（标准 r=16，40M r=8），低频基底 p\_i = z\_i V\_i ∈ R^D；基础效用分 s\_base,i = w\_score^T \[z\_i; W\_x x\] + b\_stat,i + Δb\_pre,i（静态偏置 b\_stat 强制零均值中心化 Σ\_i b\_stat,i = 0）。

**轨二 Hyper-Router 与双极原型纯前向更新：**预思考结束时由双池化隐状态一步生成 Δb\_pre = W\_hr2 · SiLU(W\_hr1 \[h\_prompt; h\_skel\])（W\_hr2 零初始化）。正式思考高难收敛帧（首拍 u\_epistemic > 0.35 且末拍 Margin > 0.65、u\_acute < 0.30）对功臣专家更新正极原型 P\_i^+ ← Normalize(0.8 P\_i^+ + 0.2 z̄\_i) 与协同增益 ΔM\_syn^+；一旦触发红灯熔断或后思考锁定病灶帧 b\*（跨回滚永久保留！），对病灶主力专家刻入痛觉烙印 P\_i^- ← Normalize(γ\_pain P\_i^- + (1 - γ\_pain) z̄\_i^(b\*))（每推进一健康帧按 γ\_pain = 0.85 衰减），清零错帧 ΔM\_syn^+ 并按克星矩阵增强 ΔM\_adv^+。

**轨二双极经验分：**s\_mem,i = λ\_+ · relu(cos(z\_i, P\_i^+)) - λ\_- · clamp(relu(cos(z\_i, P\_i^-)), 0, c\_pain\_max)（未写入时 P\_i^± = 0，余弦项为 0）。

**行归一化双极关联图与单跳保界打分（0.40 + 0.45 = 0.85 < 1）：**正常态有效图 M\_eff = T\_r(M\_syn + clip(ΔM\_syn^+, 0, 0.25))，红灯或后思考切对抗图 M\_eff = T\_r(M\_adv + clip(ΔM\_adv^+, 0, 0.25))（T\_r 为行 l\_1 归一化，保概率转移范数 ≡ 1）；记 a\_prev 为跨帧/上拍源激活画像（首拍承接上一干净帧定稿画像），综合打分：

s = s\_base + s\_mem + 0.40 · (M\_eff^T · a\_prev) + 0.45 · (M\_inter^T · a^(l-1))   （有向转置 M^T a 精确对齐“前驱/主犯 → 搭档/克星”指向，层内+跨层总阻尼 0.85 < 1 严格杜绝深层雪崩）。

### 2. Static Engram 抗 \[MASK\] 三路哈希与首拍门槛拔河护栏

**三路抗 \[MASK\] 质数桶查表（仅挂 l ∈ {4,16}，40M 挂 l ∈ {2,6}）：**给定当前输入符号序列 Y\_in，H 个哈希头分三组提取离散上下文键（每组模大质数桶 B\_eng）：① 帧头算子 OP\_head 与当前槽二元组合哈希；② 同微步已揭开粗细 FSQ 对偶共振哈希；③ 块内向左跳过 \[MASK\] 的最近有效双符号跳过哈希。若当前槽 Y\_in\[n\] ∈ {\[MASK\], <PAD>}，查表向量硬短路清零 e\_raw\[n\] = 0；随后经零初始化块内双向 Conv1D(kernel=3, padding=1) 聚合局部已揭开邻域得到 e\_conv，计算语境门控 α\_eng = sigmoid(w\_eng^T \[x\_n; e\_conv\]) 并注入残差 x\_n ← x\_n + α\_eng · (e\_conv W\_V^eng)，严保四拍交叉伪似然 PLL 评估零目标泄漏。

**首拍门槛拔河修复与封顶律：**令当前块非 \[MASK\] 有效占比为 r\_clean ∈ \[0, 1\]，定义 α\_eng\_eff = r\_clean · stop\_grad(α\_eng)，三因子动态门槛 τ = τ\_0 + w\_t · t\_k + w\_e · α\_eng\_eff - w\_u · u\_epistemic + δ\_FiLM(d\_b)。当 r\_clean < 0.25（第 1 拍高噪起草）时施加上限 K\_max^(step1) = min(K\_max, 2)，杜绝首拍因 \[MASK\] 短路清零误召过多全秩专家。

### 3. 护栏二：4.5B / 40M（8 专家小池）的痛觉死锁保护

• 痛觉扣分上限裁剪：锁定 c\_pain\_max = 0.60（且每成功推进一帧按 γ\_pain = 0.85 衰减旧痛觉），防止连续 2 次熔断把主力专家永久扣死。

• 最小活跃专家兜底配额（K\_min\_guard = 1）：在正式思考低噪拍（t\_k ≤ 0.5）或后思考阶段，若过门槛专家数为 0 且黄灯 u\_epistemic > 0.35，强制放行“非当前错帧主犯且综合分 s\_i 最高”的 1 位路由专家并赋最小兜底门控 g\_min = 0.25，确保不退化为仅靠共享微专家硬扛。

### 4. 容量卡位 C⁰ 连续归零门控与路由加权合成

**容量卡位有效门槛（兼顾静态桶与双向 C⁰ 连续）：**记 s\_(K\_max + 1) 为当前槽第 K\_max + 1 高综合分（当 K\_max = 0 时取 +∞，当 K\_max = E 时取 -∞），定义有效门槛 τ\_eff = max(τ, s\_(K\_max + 1))，连续归零门控 g\_i = relu(s\_i - τ\_eff) / (relu(s\_i - τ\_eff) + κ)（κ = 0.5）。该设计既 100% 保证每槽至多 K\_max 个专家满足 g\_i > 0（零溢出适配静态容量桶 \[N, K\_max\]），又在跨越 τ 与第 K\_max 名次交替两处边界均严格 C⁰ 连续归零。

**探针路由加权与全秩残差合成：**记归一化路由分布 w\_i = Softmax\_i(s\_i / T\_s)，有界免费自引导系数 ρ\_guide ∈ \[1.0, 1.25\]（常规取 1.0，u\_epistemic > 0.5 或后思考高难期线性外推），层统一输出为：

y = y\_shared + α\_upcycle · \[ Σ\_{i=1}^E w\_i p\_i + Σ\_{i: g\_i > 0} w\_i g\_i · ρ\_guide · (F\_i(x) - p\_i) \]

当预思考强制 K\_max = 0（g\_i ≡ 0）时，层输出平滑收口为 y\_shared + α\_upcycle · Σ\_i w\_i p\_i，使 Hyper-Router 初值 Δb\_pre 与关联图在零全秩访存下依然全效调控专家表征。

## 2.4 四维多方向扩散向量 d\_b 与动态块长调度

从中间核心层（4.5B/8.9B 取 l = 16；40M 取 l = 4）取当前块有效槽位隐状态均值 h\_pool，拼接 \[h\_pool; u\_epistemic; u\_acute; t\_k; r\_clean\]，经两层轻量化 MLP（瓶颈维 64，总参 < 0.1M）输出：d\_b = sigmoid(MLP(h\_ctx)) = \[d\_fwd, d\_bwd, d\_hier, d\_div\] ∈ (0, 1)^4


四轴控制契约：


1. **顺推与块长切换（d\_fwd）**：出现 ⟨LONG\_FRAME⟩ 或满足 d\_fwd > 0.75 且 u\_epistemic < 0.25 时，下一块切 B = 64；若 u\_epistemic > 0.55 或 d\_div > 0.65，缩至 B = 16 精细慢推；其余默认 B = 32。
1. **湿水泥向后微扩散（d\_bwd）**：当 d\_bwd > 0.55 时，对上一块末尾 16 槽按重掩码率 p\_remask = 0.15 + 0.15 · (d\_bwd - 0.55) / 0.45 ∈ \[15%, 30%\] 挑选置信度最低的槽位重掩码揉平接缝。
1. **粗细细化斜率（d\_hier）**：调节三拍解掩码中粗码（FSQ-1）与细码（FSQ-2）的 Margin 锁定阈值，d\_hier 越高越优先先锁粗码骨架。
1. **横向避坑轴（d\_div）**：熔断重推时由控制器强制拉高 d\_div ≥ 0.80，经 FiLM 放大探针正交多样性并切换对抗图 M\_adv。

## 3.2 三关合成任务数据契约与 Gate 1 裁决标准

### 1. 关卡 1（路由与联动 + Engram，约 15 万条程序合成）

- **任务结构**：单题串联“字符串解码 → 模算术 → 6 节点最短路 → 布尔校验"4 种异构技能，强制块间专家切换。
- **Gate 1 红线**：同活跃 FLOPs 准确率高于静态 Top-2 基线 ≥ 2%（或同精度活跃算力降 ≥ 15%）；评分器 Kendall τ > 0.30；std(α\_eng) ≥ 0.08。

### 2. 关卡 2（纯前向双轨 + 湿水泥 + 痛觉熔断，约 12 万条程序合成）

- **任务结构**：三合一短板题——（a）30–45 步长链寄存器覆写外推；（b）训练集零重叠的新运算符规则迁移；（c）4×4 数独与注入上游污染的错稿回溯修复。
- **Gate 1 红线**：全面压过纯 Block-dLLM，回溯题跑赢等推理墙钟 Best-of-N AR 基线；痛觉烙印后同坑二次复发率 ≤ 20%；后思考净修复率 NetFix ≥ 0。

### 3. 关卡 3（三元符号思维链提速，约 8 万条程序合成）

- **任务结构**：同一求解抽象语法树（AST）分别渲染为自然语言 CoT 与紧凑符号帧，双轨独立训练。
- **Gate 1 红线**：终答 Exact Match 不低于文本 CoT，且在本地 RTX 5080 上开启 `torch.compile` 后实测墙钟耗时降低 ≥ 2×。

## 五、AVL-PMLv1.2 第一性原理纠偏与双域数学契约修订（2026-11-25）

在进入 Stage 3 双域训练与 4B 级真实评测前，经源码级对抗审计与本地 RTX 5080 真题对拍，对第二章至第四章的数学契约做出以下 **6 项强制修订**（全部已在源码落地并通过 `pytest` **22/22** 对抗单测验证）：

### 5.1 后缀写目标精确消歧算子与 `ESC_*` 连续隐态白板写入（修正 §2.2.2，修复 P0-2）

1. **帧首只读 vs 帧尾重申写消歧：** 原 §2.2.2 将凡紧随 `⟨BIND⟩ / ⟨VERIFY⟩ / ⟨COMMIT⟩` 之后的 `⟨REG_j⟩` 一律判为写入目标，导致终答帧首 `[⟨COMMIT⟩, ⟨REG_j⟩, ...]`（占全库 97.3%）被误判为写槽而屏蔽硬索引读取，并误抓 `t-2` 处上一帧末尾填充符 `=` 覆写终答寄存器。现将后缀写目标指示函数严格修正为：
   - `is_postfix_write_dst(t) = is_rw_reg(y_t) ∧ [ (y_{t-1} = ⟨BIND⟩) ∨ (y_{t-1} ∈ {⟨VERIFY⟩, ⟨COMMIT⟩} ∧ is_value_bearing(y_{t-2})) ]`
   - 其中 `is_value_bearing(y) = (op_end ≤ y < ro_start) ∧ (y ∉ {id("="), id(":")})`。由此帧首 `[⟨COMMIT⟩/⟨VERIFY⟩, ⟨REG_j⟩]` 因其 `t-2` 为上一帧结尾算子/填充符而恒满足 `is_postfix_write_dst = False`，严格走硬索引读取（`u_epistemic = 0`）。
2. **逃生桶连续隐态直写（`continuous_esc_whiteboard`）：** 针对超出 512 个无损 `V_lit` 原语、落入多对一模哈希桶 `V_esc`（`ESC_0..2047`）的多位数或中间量，当 `y_{t-2} ∈ V_esc` 时，不再将碰撞词嵌入写入 `S^RW[j]`，而是直接取左脑在该位置计算出的连续隐状态 `x_{t-2}` 经 `ro_init_proj` 投影写入：`v_j = ro_init_proj(x_{t-2}) + 0.15 · W_v h_reg`，从根源上消除 `ESC_*` 桶碰撞造成的寄存器表征退化。

### 5.2 自然语言双域 `S^RO` 字符区间—单数字 BPE 对齐映射（补齐 §2.2.1，修复 P0-3）

针对 `Qwen3` 分词器将多位数逐字符切分为单数字 token（如 `"1st" → ["1", "st"]`、`"v1" → ["v", "1"]`、`"-12" → ["-", "1", "2"]`、`"3/4" → ["3", "/", "4"]`）的特性，定义编译器、双域前向与外部执行器三端共享的规范数值跨度提取算子 `extract_prompt_number_spans(Q)`（排除序数词后缀、字母数字标识符粘连及幂指数后缀），将第 `k` 个数值的字符区间 `[c_k^start, c_k^end)` 精确投射至 Prompt 子词累计字符区间，构造行归一化跨度池化矩阵 `W_ro ∈ R^(B × N_ro × P_nl)`：
- `S^RO[:, k, :] = SlotNorm(ro_init_proj( ∑_{p=0}^{P_nl-1} W_ro[:, k, p] · H_prompt[:, p, :] ))`，`m^RO[:, k] = I(∑_p W_ro[:, k, p] > 0)`。

### 5.3 严格保序操作数 IR 与全满 512 槽无损原语表（修正 §1.2 & §2.1，修复 P0-4）

- `MicroStepIR` 废弃将输入无序拆分为先排 `in_refs` 再排 `var_deps` 的旧约定，改由严格从左到右保序的 `operands = [o_1, ..., o_m]`（允许混合 `⟨IN_k⟩`、`$v_r`、重复操作数 `$v_r * $v_r` 及非题面隐含字面常量如 `12, 60, 100`）统一生成帧头序列，彻底根除非交换算子（`-` / `/`）左右反序与隐含常数丢失。
- 填满 `V_lit` 全部 `512` 个无损原语槽（补齐常用小数与单位换算常数如 `144, 1760, 3600, 5280, 100000, 1000000`），使重编译后的 `mega_val_fsq.jsonl` 在 GSM8K 上的确定性外部执行器上限由 `65.26%` 跃升至 **`99.11%`（447/451）**。

### 5.4 双域 8 槽细分双流 `BD3-LM`、逐帧池化隔离与 Phase 3 块前快照审计（修复 P0-5 / P0-6 / P0-7）

1. **8 槽细分双流训推逐位等价：** 在 `forward_dual_domain(gen_mode="block_dllm")` 中，采用干净流 `Y_clean`（专供历史注意力键值与 `S^RW` 无污染顺序写入）与掩码流 `Y_noisy` 双流并行，并将 `[8, 16, 16]` 混排帧统一按物理推理粒度 `dllm_block_size = 8` 切分双向注意力窗（同时仅在 `CognitivePhase.PRE` 注入 `in_span_tag`），使训练双流前向与推理期 8 槽 Prefix-KV 逐步前向的最大绝对误差由 `1.595` 压降至 **`3.76e-6`（< 1e-5）**。

### 5.5 轨二痛觉标量衰减解耦、黄灯自监督损失与双极图初始盆地（修正 §2.2.3 & §2.3）

1. **痛觉模长衰减保留律：** 为消除 `F.normalize(P_i^-)` 将 `γ_pain^t`（`γ_pain = 0.85`）衰减重新拉回 `1.0` 的代数抵消漏洞，令 `p_strength = clamp(‖P_i^-‖_2, 0, 1)`，将轨二负向扣分修正为：
   - `s_mem,i = |λ_+| · relu(cos(z_i, P_i^+)) - |λ_-| · p_strength · clamp(relu(cos(z_i, P_i^-)), 0, c_pain_max)`
   从而严格保持每健康推进一帧痛觉惩罚按 `0.85^t` 单调指数衰减（注：Stage 0 旧 `Level 2c` 因含评测端 `-6.0` 词表扣分外挂已作废，痛觉独立收益须在此修正公式下通过零外挂回溯实验单独裁决）。
2. **黄灯预测器自监督回归项：** 为断开残差流旁路干扰并赋予 `W_pred` 有效梯度，令 `pred_r = W_pred(sg(x_t))`，在总损失中加入轻量自监督项 `0.05 · MSE(pred_r, sg(r_t))`，计算 `u_epistemic` 时对 `pred_r` 施加 `sg(·)`。
3. **双极图 Step-0 盆地初值：** 调整 `BipolarLinkageGraph` 稀疏环状偏置幅值，确保 `E = 8` 与 `E = 16` 在第 0 步即严格满足 `H_row(M_syn) ∈ [ln 2, ln 4]` 且 `cos(M_syn, M_adv) ≤ 0.20`。

### 5.6 基座活跃容量守恒铁律与 `FP32MasterAdamW` 更新契约

- **拒绝活跃容量缩水剪枝：** 对中小规模预训练基座（如 `Qwen3-4B-Base`），严禁通过不重叠切分稠密 FFN 使单 token 活跃神经元跌破原基座 100%（实测 `28.9%` 活跃度直接引发零样本算术归零崩塌）；单卡主力配置固定采用 `moe_layer_indices = []`（`model_4b_dense_pml.yaml`，`4.111B` 100% 稠密 FFN），MoE 路由研究须基于复制加噪真扩容（Active FFN ≥ 100% Base）。
